# Manual de usuario

1. Abrir la aplicación en el navegador.
2. Consultar **Agenda de eventos**.
3. Cada tarjeta muestra comunidad, título, fecha/hora de inicio y fin y ubicación.
   Las horas se ajustan al huso horario del dispositivo.

Durante la consulta aparece «Cargando eventos…». Si no hay documentos publicados,
se informa de que todavía no hay eventos. Si falla la conexión, pulsar
**Reintentar**; si persiste, contactar con el responsable de la comunidad.

La pantalla se adapta a móvil y escritorio y permite navegación con teclado.
No requiere cuenta. Esta primera versión no permite crear eventos, inscribirse,
publicar contenido ni conectar redes sociales.

El evento «Encuentro de la comunidad · demo» solo existe en el modo local en
memoria: no es un anuncio real. La versión desplegada lee el catálogo Cosmos
publicado por el operador.
